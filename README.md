# PlayStation Store UA — бот скидок

Две части в одном процессе:

1. **Коллектор** круглосуточно обходит каталог PlayStation Store Украина (PS4 и PS5), пишет игры и историю цен в SQLite.
2. **Бот** показывает уже нашу базу: платформа → жанр → игры. Поиск тоже идёт по базе, не по стору.

При изменении цены:

- сообщение в канал (все изменения);
- личка тем, кто нажал «Следить» на этой игре.

Первый проход только наполняет базу, без уведомлений.

Сервер от root: [DEPLOY.md](DEPLOY.md).

## Запуск локально

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

В `.env`:

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `CHANNEL_ID` — id канала (`-100...`). Бот должен быть **админом** канала
- `ADMIN_IDS` — необязательно, свой telegram id для `/stats`

```text
python main.py
```

Коллектор ходит медленно: **2 с** между запросами к магазину, полный обход цен раз в **~2 часа**. Жанры обновляются раз в 6 циклов (примерно раз в сутки). Скидки в сторе висят днями, быстрее не нужно.

Только коллектор, без бота:

```text
python collector_main.py
```

## Меню бота

- **Поиск** — инлайн по нашей базе: вводишь название, сверху выпадают игры
- **Каталог** — PS4 / PS5 / обе → жанр → листать игры
- **Скидки** — то же, только со скидкой
- **Мои игры** — подписки

Инлайн нужно один раз включить у [@BotFather](https://t.me/BotFather): `/mybots` → бот → Bot Settings → Inline Mode → Turn on. Placeholder: `Название игры`.

На карточке: текущая цена, зачёркнутая старая, история, «Следить».

## Регион

Магазин: `uk-ua`, валюта гривна. Российский PSN закрыт, поэтому регион зафиксирован на Украине.

Цены берутся из GraphQL-каталога самого магазина (`categoryGridRetrieve`). Если Sony сменит подпись запроса, коллектор начнёт писать ошибки в лог — тогда нужно обновить `SHA_CATEGORY_GRID` в `bot/psn.py`.
